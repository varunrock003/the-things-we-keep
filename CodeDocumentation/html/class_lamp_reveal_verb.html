Detailed Description

Reveal verb for the lamp. Listens to the PossessableObject on the same GameObject: possess the lamp with E, press Space, and the lamp fades on and uncovers a hidden clue.

The lamp's Light component is switched by this script, so leave the LampLight GameObject itself active in the Hierarchy. The script turns the light off on Start. Do not also wire ActivateReveal into the PossessableObject's onVerbUsed event in the Inspector, because the script subscribes itself and the reveal would run twice.
