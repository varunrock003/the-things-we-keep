# Unity project setup — planned for Milestone 2

**Status as of October 21, 2026: no Unity project has been created or committed here yet.** This file reserves the intended project location and documents the next phase. It is not evidence of engine installation or a working scene.

## Target setup
- Engine: Unity 6.3 LTS (team setup plan references editor version 6000.3.25f1)
- Template: Universal 3D (URP)
- Platform: Windows PC build target
- Game: fixed-camera 3D dollhouse diorama, not a free-roam first-person game

## Milestone 2 checklist
1. Clone the repo locally and run `git lfs install`.
2. Open Unity Hub and create a new Universal 3D project inside `unity/` (or a clear child folder).
3. Open and save the starting scene as `Kitchen.unity`.
4. Commit the real Unity source folders: `Assets/`, `Packages/`, `ProjectSettings/` and `.meta` files. Do **not** commit `Library/`, `Temp/`, or `Build/`.
5. Check the pushed project opens cleanly on another teammate's machine.
6. Record real test results and screenshots before claiming anything playable.

When the Unity project is created, update this note with the **actual** folder path, editor version, test machine and commit link.
